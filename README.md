This is the curated, reversible working copy of the attached 71-file research archive. It contains 48 PDF manuscripts, source companions, research records, seven finite sanity checks, and a responsive catalog.

## Open the library

- **Start:** [`docs/index.html`](docs/index.html) — catalog, two-dimensional ratings, full-text search.
- **Core theory:** [`docs/theory.html`](docs/theory.html) or [`core/CORE_THEORY_GUIDE.md`](core/CORE_THEORY_GUIDE.md).
- **Finite demonstration:** [`docs/lab.html`](docs/lab.html) — small W1/W2/W3 examples.
- **Meaning-based search:** [`docs/semantic-search.html`](docs/semantic-search.html) — optional on-device embedding model, currently catalog-metadata scope.
- **Original source files:** [`library/`](library/) — unchanged from the selected archive.
- **Editorial ratings:** [`ratings/`](ratings/) and [`docs/catalog.js`](docs/catalog.js).

Run `python -m http.server 8000` from the repository root and visit `http://localhost:8000/docs/` for a local browser preview. Works on desktop and responsive mobile-sized screens. Do **not** enable GitHub Pages or a public hosting service while the research is private.

## Independent evidence and limitations

The user-supplied Python checker tests seven finite examples; it does not establish a general self-improving theorem prover. The browser finite-game lab is illustrative. Research scores are provisional, and inclusion is not proof certification. Semantic search uses optional on-device ML downloaded from a third-party CDN; the ordinary catalog and full-text search run without any API or CDN. No paid AI API is required.

## Before any public release

Review files, private data, attribution, research statuses, publication rights, and all prototype/verification claims. Only then consider enabling public GitHub Pages. A private repository does not itself guarantee that Pages content would remain private if Pages were enabled.
