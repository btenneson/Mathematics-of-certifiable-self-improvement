# Publish the research website without changing repository privacy

**Keep the repository private. The website can be public.** The Pages-ready site is assembled in `docs/` with its own static assets, the curated research documents and 2D ratings file.

## Activate the site as the repository owner

1. Open https://github.com/btenneson/Mathematics-of-certifiable-self-improvement/settings/pages
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/docs**, then **Save**.
4. After GitHub reports a successful deployment, open https://btenneson.github.io/Mathematics-of-certifiable-self-improvement/

GitHub Pages from a private repository is available on GitHub Pro, Team and Enterprise plans, not GitHub Free. Ownership controls access to settings, but does not bypass that plan rule. If GitHub does not offer Pages with the repository private, do **not** change visibility. This requires an eligible plan or an alternative public website host.

All content placed under `docs/`, including published PDFs, is publicly accessible after activation. The entire GitHub repository itself remains private.

The assistant can update the repository files but cannot activate GitHub Pages in the owner's settings using the currently connected GitHub tools.

## Future changes

`docs/library/` is a publishing snapshot of `library/`. Update the corresponding copy when an original file changes, and check catalog links. Avoid adding material not meant to appear on the public website.
