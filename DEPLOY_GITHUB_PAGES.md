# Publish the research website

The Pages-ready website is in `docs/`. A public source repository supports Pages on GitHub Free; a private source repository requires an eligible paid plan.

## Owner settings

1. Open https://github.com/btenneson/Mathematics-of-certifiable-self-improvement/settings/pages
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/docs**, then **Save**.
4. Verify https://btenneson.github.io/Mathematics-of-certifiable-self-improvement/ after a successful deployment, using a signed-out browser.

All files under `docs/` are publicly accessible once the public site is deployed. Changing repository visibility to public additionally exposes the rest of the repository, including internal ratings and Git history. Review those materials before changing visibility. The connected assistant can update files but cannot change repository visibility or Pages settings.

## Future uploads

Ask the research director “pub or self-improvement?” before a new publication upload. For self-improvement, put approved public files in `docs/library/`, add catalog metadata, preserve originals, and verify links. The root `library/` is a historical archive and may differ from the website snapshot. Do not invent missing sources or claim verification from catalog inclusion.
