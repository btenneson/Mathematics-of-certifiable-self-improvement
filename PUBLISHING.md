# Publication checklist

The GitHub repository is currently private. This file **does not turn it public or activate GitHub Pages**.

## Before publishing

- [ ] Check the seven [missing source records](MISSING_FILES.md). Decide whether to upload exact originals or explicitly remove those catalog entries.
- [ ] Check manuscripts for personal contact details, private transcripts, unpublished collaboration, third-party rights, and intended attribution.
- [ ] Review the 2D editorial research/relevance ratings; they are not external review.
- [ ] Confirm research-status caveats, retired FORGE-6 records, and finite-only experimental verification scope.
- [ ] Check that the repository license and re-use permissions reflect the research director's intent; no license is added automatically.
- [ ] Verify each website page and 48 PDF links in a desktop and mobile browser after publication.

## Publish when approved

1. In GitHub open this repository's **Settings → General → Danger Zone → Change repository visibility → Public**. Publishing exposes its full commit history, not only the website.
2. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/docs**, and save.
3. Confirm successful deployment and open `https://btenneson.github.io/Mathematics-of-certifiable-self-improvement/`.
4. Optionally add this link to the existing `pub` index and GitHub repository description.

GitHub Pages hosting is free for public repositories on GitHub Free; no paid AI API is needed. The meaning-based search requires the optional model download. The public site links PDFs to GitHub repository files rather than assuming directories outside the Pages publication root are served.
